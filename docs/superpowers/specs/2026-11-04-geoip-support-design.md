# RouteScan 本地 GeoIP 与 ASN 路由分析详细设计

- **日期**: 2026-11-04
- **特性名称**: 本地 GeoIP 与自治域 (ASN) 逐跳路由分析
- **目标**: 为 RouteScan 的逐跳路由明细（L3 Trace）注入高精度的地理位置、城市归属与运营商/ASN 数据，使网络漫游轨迹一览无余。

---

## 1. 核心设计原则

1. **纯本地微秒级解析**:
   - 彻底摒弃运行期依赖外部 HTTP API 的做法，避免由于 Rate Limit、网络请求延迟而导致终端 TUI 刷新卡顿。
   - 单次 IP 检索耗时控制在纳秒/微秒级别。
2. **多级解析分流引擎**:
   - **L1 静态特征树**: RFC 1918 私有保留地址（`10.x`, `192.168.x`, `172.16-31.x`）、CGNAT 运营商局端（`100.64.x.x`）及回环地址（`127.0.0.1`）瞬时打标。
   - **L2 本地 MMDB 数据库**: 支持加载标准 MaxMind 格式（GeoLite2-City / ASN 或兼容开源库），二叉树检索国家、省份、城市、ASN 组织名。
   - **L3 平滑自愈降级**: 若本地 `~/.routescan/geoip.mmdb` 尚未下载，系统启动不阻塞，先以 L1 特征展示，后台静默拉取开源精简库并支持热重载。
3. **经典紧凑排版**:
   - 采用一体化排版展示 `IP 地址 │ 地理位置 & 运营商/AS │ RTT │ 丢包率`，自动适应 80~120 字符标准终端宽度。

---

## 2. 模块规划

```text
internal/
├── geoip/
│   ├── types.go          # GeoLocation 结构体定义
│   ├── rules.go          # RFC 1918、CGNAT 及常用骨干网特征库
│   ├── db.go             # MMDB 解析与多级 Lookup 管道
│   └── downloader.go     # 数据库自动下载与热重载管理
```

---

## 3. 字段与排版规范

在 `probe.HopInfo` 中新增：
- `Geo string`: 格式化地理位置（如 `中国 广东 广州`、`中国 香港`、`美国 加州 圣何塞`）
- `ASN string`: 自治域编号与运营商（如 `AS4134 中国电信`、`AS13335 Cloudflare`）

TUI 显示格式：
```text
  跳数   IP 地址           地理位置 & 运营商/AS                          第1次     第2次     丢包率
   1     192.168.5.1       [局域网] 本地家庭无线网关                     3.4ms     3.2ms     0.0%
   2     100.64.0.1        [局端] 城域网汇聚网关 (CGNAT)                5.1ms     4.9ms     0.0%
   3     202.97.12.34      中国 广东 广州 (AS4134 中国电信骨干)          12.8ms    12.5ms    0.0%
   6     154.21.88.99      中国 香港 (AS13335 Cloudflare 边缘)          42.1ms    41.9ms    0.0%
```
